# Журнал решений

## 2026-08-05 — Markdown вместо SQLite
**Решение:** Использовать plain markdown-файлы.
**Причина:** Human-readable, git-diffable, читаются без спецПО, соответствует Local-First.
**Пересмотреть:** При >100 000 записей или когда поиск по дате станет критически медленным.

## 2026-08-05 — Telegram вместо Event Bus / PWA
**Решение:** Telegram-бот как единственный UI.
**Причина:** Ноль кода под Android, push из коробки, vibe-coding friendly.
**Пересмотреть:** При появлении второго источника данных (почта, Obsidian, etc.).

## 2026-08-05 — 3 слоя памяти
**Решение:** stream → buffer → meta.
**Причина:** Разделение "сырой фиксации" и "курированных фактов" без нарушения Append-Only.
**Пересмотреть:** Не раньше, чем появится проблема с объемом.

## 2026-08-05 — Архитектура документации заморожена
**Решение:** 8 файлов. Новые документы — только после Этапа 2, и только если существующий перестал отвечать на свой вопрос.
**Причина:** Защита от разрастания документации быстрее кода.
**Пересмотреть:** После стабилизации Этапа 1.
