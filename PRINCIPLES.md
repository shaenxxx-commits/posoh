# Принципы POSOH / Sub-0

## 1. Данные принадлежат пользователю
Хранятся локально. Читаются без специального ПО. Если завтра отключить LLM — файлы остаются полезными.

## 2. Минимальная сложность
Абстракции только под реальную проблему. Не пишем `class MemoryEngine`, пока `open(stream.md)` не сломался.

## 3. Контекст строится на памяти. ИИ работает с контекстом
Сначала надежная память. Потом — аналитика. LLM — сервис над данными, не замена хранилищу.

## 4. Автономность: ручной → подтверждение → авто
Каждая функция проходит стадии: ручная → полуавтомат (я подтверждаю) → полная автономия. Не прыгать через ступени.

## 5. Новый модуль — только после реальной потребности
Не для гипотетического будущего. Критерий: "буду ли использовать каждую неделю в ближайший месяц?"

## 6. Документация читается за 15 минут
Если новый чат LLM не понимает проект за 15 минут чтения — документация разрослась. Сокращать.

## 7. Документ появляется только при необходимости
Документ добавляется только тогда, когда существующий документ перестает однозначно отвечать на свой вопрос.
