# POSOH / Sub-0

> Личный инструмент добровольного self-tracking. Один пользователь, собственные данные. Не surveillance, не слежка за третьими лицами.

## POSOH
Personal Operating System for One Human.
Философия и архитектурная рамка персональной AI-экосистемы.

## Sub-0
Рантайм под POSOH. Личный AI-секретарь Архитектора.
Смотрит внутрь (жизнь Архитектора), не наружу (мир).

## Что делает
- Принимает голос/фото/текст с Android через Telegram.
- Сохраняет в локальные markdown-файлы на Ubuntu (nova).
- Раз в сутки анализирует поток, выделяет факты, ищет паттерны.
- Уведомляет в Telegram при аномалиях.

## Что НЕ делает
- Не JARVIS. Не управляет умным домом, не отвечает голосом.
- Не MAIA. MAIA — внешний агент (мир → Архитектор). Sub-0 — внутренний.
- Не продукт для масштабирования. N=1, один сервер, минимум бюджета.

## Экосистема
POSOH
├── Sub-0 (внутренняя память + контекст)
├── MAIA (внешний анализ)
└── [будущие модули]
